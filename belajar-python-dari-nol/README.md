# Belajar Python dari Dasar sampai Menengah

Repository ini berisi materi belajar Python yang dipisahkan menjadi file `.py` agar mudah dipelajari satu per satu. Penjelasan konsep ditulis sebagai komentar di dalam kode, disertai contoh yang dapat dijalankan dan latihan mandiri.

## Persiapan

1. Instal Python 3.10 atau lebih baru dari <https://www.python.org/downloads/>.
2. Saat instalasi di Windows, aktifkan pilihan **Add Python to PATH** jika tersedia.
3. Buka folder repository menggunakan VS Code atau editor Python lainnya.
4. Jalankan file dari terminal dengan perintah `python nama_file.py` (di Windows, `py nama_file.py` juga dapat digunakan).

## Cara Belajar yang Disarankan

- Pelajari file sesuai nomor, jangan terburu-buru melompat ke materi lanjutan.
- Jalankan contoh kode dan amati hasilnya.
- Baca komentar untuk memahami fungsi setiap baris penting.
- Kerjakan bagian `LATIHAN` di bagian bawah file.
- Ubah contoh kode, lalu amati apa yang berubah.
- Simpan solusi latihan di file terpisah agar contoh awal tetap tersedia.

## Catatan

- Setiap file materi dapat dipelajari secara mandiri, tetapi urutan materi disusun agar konsepnya saling membangun.
- Beberapa file meminta input dari pengguna ketika dijalankan.
- File `18_file_handling.py` dan `19_json.py` akan membuat file latihan di folder kerja saat dijalankan.
- Repository ini merupakan bahan belajar. Tetap biasakan membaca dokumentasi resmi Python: <https://docs.python.org/3/tutorial/>.
